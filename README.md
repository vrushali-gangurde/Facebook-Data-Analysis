# Facebook Data Analysis

A beginner-friendly project using Python, NumPy, Pandas, Matplotlib, and Seaborn.

## Objective
Explore Facebook post metrics to compare post types and categories, inspect likes/comments/shares, identify top-liked posts, and visualize engagement patterns.

## Dataset
Keep `dataset_Facebook (1).csv` in the same folder as the notebook. This dataset is semicolon-separated, so the notebook uses `sep=";"`.

## Requirements
- Python 3
- Jupyter Notebook
- pandas, numpy, matplotlib, seaborn

Install in Command Prompt:
```bash
python -m pip install jupyter pandas numpy matplotlib seaborn
```

## Run
1. Open Jupyter Notebook.
2. Open `Facebook_Data_Analysis.ipynb`.
3. Run cells from top to bottom using Shift + Enter.

## Analysis included
- Dataset inspection and data quality checks
- NumPy descriptive statistics
- Engagement summary
- Group analysis by post type and category
- Top 10 posts by likes
- Posting-hour analysis
- Visualizations and dataset-driven findings

**Note:** Conclusions describe this sample dataset only and should not be generalized to all Facebook pages.
